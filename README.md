# AI Coding Mentor (MERN + Gemini)

## Setup
1. Get a free API key: https://aistudio.google.com/apikey
2. Install MongoDB locally, or use a free MongoDB Atlas URI.

### Server
    cd server
    npm install
    cp .env.example .env     # then edit .env and add your key
    npm run dev

### Client (new terminal)
    cd client
    npm install
    npm run dev

Open http://localhost:5173
